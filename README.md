# ♟️ PythonChess

Simple local chess game made in Python.

## What it does

- Full chess game with all standard rules
- 2-player local gameplay
- Graphical interface using Pygame
- Move validation and game logic

## Features

- Complete chess piece movements
- Check/checkmate detection
- Turn-based gameplay
- Visual board with piece graphics

## How to play

- Click piece to select
- Click destination to move
- Game enforces all chess rules
- White moves first
